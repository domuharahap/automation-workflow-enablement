# What's Next

Congratulations on completing the EdgeConnect Automation Workshop!

---

## Extend What You Built

Here are some ideas for taking this further:

- **Add more remediation workflows** — explore other Davis AI problem types (high CPU, disk saturation, service response time degradation) and build automated remediation for each
- **Scale to multiple clusters** — deploy EdgeConnect across dev, staging, and prod clusters and route workflows to the right cluster based on the problem context
- **Tighten RBAC** — review the `edgeconnect-role` permissions and scope them to only the namespaces your workflows need to touch
- **Add audit logging** — use Dynatrace Grail to query workflow execution history and build a dashboard for automation observability
